# Admin dashboard for item management

## Summary
Create an admin dashboard that allows administrators to manage items with full CRUD operations. The dashboard should support uploading new items, editing existing items, and deleting items as needed.

## Approved Story and Acceptance Criteria
## User Story
As an administrator, I want a dashboard to manage items with upload, edit, and delete capabilities so that I can maintain accurate and up-to-date item inventory for the application.

## Acceptance Criteria
- [ ] Dashboard displays a list of all existing items with key details (name, creation date, status) in a table or grid format
- [ ] Upload functionality accepts new items through file selection or drag-and-drop interface and saves them successfully to the system
- [ ] Edit functionality allows modification of item properties through a form interface and persists changes to the database
- [ ] Delete functionality removes selected items from the system after displaying a confirmation dialog to prevent accidental deletion
- [ ] All operations display clear success or error messages to inform the administrator of action results
- [ ] Dashboard is accessible via keyboard navigation and screen readers, meeting WCAG 2.1 AA standards for administrative interfaces
